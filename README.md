# 🌐 Odyssey 2K25 - Event Website

This repository contains the official website built for **Odyssey 2K25**, the flagship techno-cultural fest of **Jain College of Engineering, Belagavi**.

Odyssey 2K25 was a two-day event hosted on **11th & 12th April 2025**, bringing together innovation, culture, and collaboration. The website served as the central platform for providing information, rules, and registration access to participants across all departments.

The goal of this project was to design and develop a dynamic, responsive, and user-friendly website that:

- Showcases the core theme and branding of the fest  
- Provides centralized access to rules and registration  
- Highlights the organizing and development team  
- Encourages user engagement through clear UI/UX  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Design:** Fully responsive and mobile-friendly layout  
- **Deployment:** VERCEL  

---

## 🎨 Key Features

- Landing page with fest branding and theme  
- Responsive navigation and smooth scroll  
- Clear “Register Now” and “Rulebook Download” CTA buttons  
- Developer and academic team credits  
- Contact details with college branding
